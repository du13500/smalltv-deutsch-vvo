# SmallTV flat case v1

![SmallTV flat case v1 render](SmallTV%20flat%20case_v1.png)

A flat desk case for the SmallTV, with a matching stand. Both parts are in
one file, ready to slice:

- `SmallTV flat case_v1.stl` — binary STL (SketchUp export)
- `SmallTV flat case_v1.png` — preview render, generated with
  `tools/render_stl.py`

Re-render the preview after changing the model:

```sh
python tools/render_stl.py "case/SmallTV flat case_v1.stl" "case/SmallTV flat case_v1.png"
```
